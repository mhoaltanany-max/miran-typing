# مران الكتابة

موقع للتدرّب على الكتابة بالإنجليزي على لوحة مفاتيح الكمبيوتر، استعدادًا للاختبار الإلكتروني. كل التمارين من كلمات وقصص **مران** (٤٣٦٨ كلمة و٨٨ قصة مسجّلة).

## التشغيل بدون نت (على الكمبيوتر)

1. نزّل الملف: https://github.com/mhoaltanany-max/miran-typing/releases/latest/download/miran-typing.zip
2. فك الضغط.
3. افتح `index.html` بمتصفح Chrome أو Edge.

بيشتغل كامل بدون نت، مع الصوت. الخط بيكون خط الجهاز إذا ما في نت، وهاد ما بيأثّر على التمارين.

## الأقسام

1. **لوحة المفاتيح:** ١٢ درس متدرّج، وكيبورد على الشاشة بيضوّي الحرف الجاي وإصبعه.
2. **كتابة الكلمات:** المعنى والصوت، وبتكتب الكلمة.
3. **الإملاء:** جمل من القصص بالصوت الأصلي.
4. **النسخ والسرعة:** فقرة من قصة، مع السرعة والدقّة، ووضع مؤقّت.
5. **اختبار تجريبي:** ١٥ دقيقة، ٣ أقسام، وتقرير بالآخر.
6. **إحصائياتي:** تطوّر السرعة، والمفاتيح اللي بتغلط فيها.

## على النت

إذا فعّلت GitHub Pages (Settings ← Pages ← Branch: `main` / root)، الموقع بيفتح على https://mhoaltanany-max.github.io/miran-typing/ وبيحفظ حاله أول مرة عشان يفتح بعدين بدون نت.
